# Scripts

This directory contains utility scripts for data processing and model training.

## Files

- `data_loader.py` - Load and preprocess raw datasets
- `feature_engineer.py` - Feature engineering pipeline
- `train.py` - Model training and evaluation
- `evaluate.py` - Model evaluation utilities
- `shap_analysis.py` - SHAP explainability analysis

## Usage

```bash
# Example
python scripts/data_loader.py --input data/raw --output data/processed
```
