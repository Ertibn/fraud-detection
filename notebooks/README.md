# Notebooks

Jupyter notebooks for fraud detection analysis and modeling.

## Files

### EDA Notebooks
- **eda-fraud-data.ipynb** - Exploratory analysis of e-commerce transactions
- **eda-creditcard.ipynb** - Exploratory analysis of bank credit card transactions

### Feature Engineering
- **feature-engineering.ipynb** - Feature extraction and engineering pipeline

### Modeling
- **modeling.ipynb** - Model building, training, and evaluation

### Explainability
- **shap-explainability.ipynb** - SHAP analysis and business recommendations

## Execution Order

1. `eda-fraud-data.ipynb` - Understand e-commerce data
2. `eda-creditcard.ipynb` - Understand credit card data
3. `feature-engineering.ipynb` - Create features for modeling
4. `modeling.ipynb` - Train and evaluate models
5. `shap-explainability.ipynb` - Interpret best model and generate recommendations
